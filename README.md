# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

### 剩余敞口（部分冲正）

冲正额度不活在单轮内存里，而是按正向流水键物化到独立敞口表 `forward_exposures`：

- **剩余敞口 = 原金额 − 已成功冲正累计**；每次冲正配平成功即在同一事务内改写，状态为 `未冲 / 部分冲 / 已闭口`（剩余 0 即闭口）。
- 新冲正不得超过当前剩余敞口；**超额整笔失败**进未平隔离，隔离项写明「冲正超额」、当时敞口与超额，绝不部分扣账、也不先扣余额再改状态。
- 提交形态：**单数据库事务**（`BEGIN IMMEDIATE`）保证余额 / 敞口 / 隔离 / 流水状态同成败。
- 归并报告里的已冲累计、剩余敞口合计、闭口数、超额隔离笔数、敞口不符数全部由敞口表 / 流水状态 / 隔离表 / 账户余额派生，刷新与重启后仍可查。
- 余额由「全部正式已归并流水」派生后覆盖写，重复归并不会按原金额重复扣。

接口：`GET /api/exposures` 列出每笔正向的剩余敞口；`/api/entries?kind=正向` 每行带 `exposure_*` 列；`/api/quarantine` 超额项带 `excess_cents` / `exposure_cents`。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。

## 与已有仓差异

| 仓 | 骨架 |

| Tiercraft | 贴源→明细→汇总→层间对账 |
| Shiftboard | 班次归属→交班互斥→批次过户 |
